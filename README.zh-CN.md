# Go 进程内缓存

[English](README.md)

一个用 Go 编写的进程内键值缓存。示例使用简单的缓存接口写入和读取 Go 值、删除条目、统计键的数量，并清空缓存。

## 实现

- [cache](cache) 使用 map 存储条目，估算各个值的大小。可以配置大小上限，写入时也可以传入 TTL。当前实现可能把 TTL 大于零的条目立即判定为过期。
- [cache_server](cache_server) 将内存缓存封装为 Go 接口。每个实例都应先设置上限再写入数据，当前实现超限时会退出进程。
- [test](test) 包含取值、过期和大小限制的练习用例。

## 运行示例

[Go 模块](go.mod)声明 Go 1.19。在仓库根目录运行示例。

```sh
go run .
```
